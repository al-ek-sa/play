# Архитектура

Описание архитектуры проекта Locus: модули, поток данных, хранение состояния, как добавить новый уровень.

## Общая схема

1. Пользователь → Карта уровней (index.html)
2. Клик по кнопке уровня → Модальное окно с теорией
3. Кнопка «Теория прочитана» → Страница уровня (lvN.html)
4. Ввод ответа → Проверка + сохранение в localStorage
5. Страница истории (Nlv--history.html)

## Модули JavaScript

| Модуль | Ответственность |
|---|---|
| `app.js` | Точка входа, инициализация всех модулей |
| `modal.js` | Открытие модальных окон с теорией |
| `navigation.js` | Переходы между страницами |
| `level1.js` | Логика уровня 1 (квадрат) |
| `level2.js` | Логика уровня 2 (круг) |
| `level3.js` | Логика уровня 3 (треугольник) |
| `canvas.js` | Фабрика canvas для отрисовки |
| `history.js` | Фабрика истории с пагинацией |

### app.js

Точка входа приложения. Запускает все модули после загрузки DOM:

- `initModal()` — открытие модальных окон с теорией
- `initNavigation()` — переходы между страницами
- `initLevel1/2/3()` — логика теории для уровней
- `level1/2/3()` — логика игры для уровней
- `initHistoryPage()` — рендер страниц истории

Модули запускаются условно: если на странице есть соответствующий элемент (форма, tbody), модуль инициализируется.

### modal.js

Открывает модальные окна с теорией по клику на кнопки уровней. Каждая кнопка связана со своим модальным окном:

- `lv-one` → `th-square`
- `lv-two` → `th-circle`
- `lv-tree` → `th-triangle`

### navigation.js

Обрабатывает переходы между страницами:

- Карта → уровень: кнопки `lv1`, `lv2`, `lv3`
- Уровень → история: `history--Nlv`
- Уровень → карта: `exit--Nlv`
- История → уровень: `history-back-lvN`
- Модальное окно результата: `success--next--lvN`, `success--exit--lvN`, `failure-lvN`

### level1.js / level2.js / level3.js

Каждый модуль экспортирует две функции:

- `initLevelN()` — логика теории: форма с полями, валидация, отрисовка фигуры на canvas.
- `levelN()` — логика игры: поле ввода ответа, проверка, запись в историю, показ модального окна результата.

### canvas.js

Фабрика `createCanvas(id)` возвращает объект с API для рисования:

- `drawSquare(a, x, y)` — квадрат с половиной стороны a и центром (x, y)
- `drawCircle(r, x, y)` — круг с радиусом r и центром (x, y)
- `drawTriangle(p1, p2, p3)` — треугольник по трём вершинам
- `drawPoint(x, y)` — точка в координатах (x, y)
- `redraw()` — перерисовка плоскости и сетки

Внутри вычисляются коэффициенты `b = width / 40` и `c = height / 40` для перевода координат из мира в пиксели. Ось Y инвертируется для математически корректной системы координат.

### history.js

Фабрика `createHistory(id)` возвращает объект с методами:

- `add(answer, isCorrect)` — добавить запись
- `render()` — перерисовать таблицу
- `initPagination()` — навесить обработчики пагинации
- `initClear()` — навесить обработчик очистки

Использует `localStorage` для хранения, пагинацию по 10 записей, `async` / `await`.

## Хранение состояния

### localStorage

Ключи формируются по шаблону `history:${id}`, где `id` — идентификатор уровня:

- `history:lv1` — история уровня 1
- `history:lv2` — история уровня 2
- `history:lv3` — история уровня 3

Формат записи:

```json
{
  "answer": "5",
  "isCorrect": true,
  "date": "2026-09-27T10:30:00.000Z"
}
```

При загрузке страницы истории модуль читает массив из localStorage, применяет пагинацию и рендерит таблицу.

### Состояние в памяти

Состояние canvas (масштаб, позиция) не сохраняется между перезагрузками. При каждом открытии страницы canvas пересоздаётся с нуля.

## Поток данных

### Теория

1. Пользователь открывает `index.html`.
2. `app.js` вызывает `initModal()` и `initNavigation()`.
3. Клик на кнопку уровня → `modal.classList.add('active')`.
4. Внутри модального окна — форма с полями ввода.
5. Пользователь вводит значения, нажимает «Посмотреть значение».
6. `initLevelN()` валидирует данные и вызывает `plane.drawSquare/Circle/Triangle`.
7. Клик на «Теория прочитана» → `window.location.href = 'lvN.html'`.

### Игра

1. Пользователь открывает `lvN.html`.
2. `app.js` вызывает `levelN()`.
3. Пользователь вводит ответ, жмёт «Отправить на проверку».
4. `levelN()` валидирует ответ, сравнивает с правильным.
5. Рисует фигуру и точку на canvas.
6. Вызывает `history.add(answer, isCorrect)`.
7. Показывает модальное окно «правильно» или «неверно».

### История

1. Пользователь открывает `Nlv--history.html`.
2. `app.js` вызывает `initHistoryPage('lvN')`.
3. `createHistory(id)` читает данные из localStorage.
4. `render()` рендерит таблицу с пагинацией.
5. Кнопки «предыдущая» / «следующая» переключают страницы.
6. Кнопка «Очистить историю» удаляет все записи с подтверждением.

## Стили

Стили вынесены в `css/style.css`. Reset.css подключён первым в `<head>` через CDN (jsdelivr).

Основные принципы:

- Блочная вёрстка через `display: flex`.
- Единая палитра: antiquewhite, #9a7951, #e1ceb9, #3b3019, #45361c.
- Единый шрифт JetBrains Mono ExtraBold, serif.
- Кастомный скролл через `scrollbar-color`, `scrollbar-width`.
- Псевдоэлементы `::before` и `::after` для маркеров и декора.
- Псевдоклассы `:hover`, `:focus`, `:active`, `:invalid`.
- Дочерние и атрибутные селекторы.
- Адаптивные размеры через `clamp()` и `aspect-ratio`.

## Как добавить новый уровень

### 1. Создать модуль логики

Создать `js/levelN.js` с функциями:

```js
export function initLevelN() {}
export function levelN() {}
```

### 2. Добавить импорт в app.js

```js
import { initLevelN, levelN } from './levelN.js';

if (document.getElementById('form-lv-N')) {
  initLevelN();
}
if (document.getElementById('form-lvN')) {
  levelN();
}
```

### 3. Добавить в index.html

- Модальное `<div id="th-figure" class="modal">` с теорией, формой и canvas.
- Кнопку «Теория прочитана».

### 4. Создать страницу уровня

Создать `html/lvN.html` с:

- Шапкой (`level-header`) с кнопками «история», «выйти».
- Формой с полем ответа.
- Canvas для отрисовки.
- Модальные окна результата.

### 5. Создать страницу истории

Создать `html/Nlv--history.html` с:

- Шапкой с кнопкой «К уровню».
- Таблицей истории.
- Кнопками пагинации и очистки.

### 6. Добавить в navigation.js

- Переход на `lvN.html`.
- Переход на `Nlv--history.html`.
- Возврат на карту.

### 7. Добавить данные в data/data.json

Для дальнейшего использования при генерации заданий.

### 8. Обновить документацию

- `CHANGELOG.md` — что добавлено.
- `docs/LEVELS.md` — формулы и правила нового уровня.
- `README.md` — если изменился обзор.

## Ограничения

- Координатная плоскость ограничена диапазоном [−10, 10] по обеим осям.
- Ответы уровней 2 и 3 пока захардкожены — вычисление по формуле планируется в следующих версиях.
- Серверная часть отсутствует — вся логика на клиенте.
- Состояние canvas не сохраняется между перезагрузками.
