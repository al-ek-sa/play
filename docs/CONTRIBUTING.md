# Соглашение о коммитах

Проект использует [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/) — стандарт для сообщений коммитов.

Правила применяются к коммитам с момента добавления этого файла. Ранние коммиты могли не соответствовать стандарту — история не переписывается.

## Формат

```
<тип>: <краткое описание>
```

## Типы

| Тип | Когда использовать |
|---|---|
| `feat` | Новая функциональность |
| `fix` | Исправление бага |
| `refactor` | Изменение кода без изменения поведения |
| `style` | Форматирование (отступы, кавычки, точки с запятой) |
| `docs` | Документация, комментарии |
| `test` | Тесты |
| `chore` | Рутина: зависимости, конфиги, `.gitignore` |
| `perf` | Улучшение производительности |
| `build` | Сборка, зависимости |
| `ci` | Настройка CI/CD |
| `revert` | Откат предыдущего коммита |

## Правила

- **Язык** — английский.
- **Время** — настоящее (`add`, не `added`).
- **Длина заголовка** — до 50 символов.
- **Заглавная буква** — только в типе, в описании — строчная.
- **Точка в конце** — не ставить.
- **Тело коммита** — если нужно объяснить подробнее, через пустую строку после заголовка.
- **Один коммит — одна задача**.
- **Частые коммиты** — не один большой.

## Примеры

```
docs: add LEVELS.md
feat: add theory form for level 1
fix: handle NaN in square coordinates
refactor: extract validateField to shared module
style: format CSS properties
chore: add reset.css
```

## Пример с телом

```
fix: prevent button shifting on error

The button was moving when a long error message appeared.
Fixed by replacing height: 6% with min-height: 16px in .field-error.
```
