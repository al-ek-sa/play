# Уровни

Описание всех уровней игры: фигуры, формулы, условия
задач и правильные ответы.

## Общая структура

Каждый уровень состоит из двух частей:

1. **Теория** — модальное окно с объяснением фигуры, формулами
   и интерактивной формой для экспериментов.
2. **Игра** — страница с задачей, полем ввода ответа и проверкой.

Во всех уровнях координатная плоскость ограничена диапазоном
от −10 до 10 по обеим осям. Это связано с размером canvas
(40 × 40 единиц) и валидацией вводимых данных.

## Уровень 1 — Квадрат

### Фигура

Квадрат — фигура с четырьмя равными сторонами и четырьмя
прямыми углами.

### Формула попадания

Точка (x, y) находится внутри квадрата с центром (x₀, y₀)
и половиной стороны a, если выполняются оба условия:

```
|x − x₀| ≤ a
|y − y₀| ≤ a
```


### Границы квадрата

- левая граница:  x = x₀ − a
- правая граница: x = x₀ + a
- нижняя граница: y = y₀ − a
- верхняя граница: y = y₀ + a

### Теория (модалка)

**Что дано:**
- a — половина стороны квадрата, диапазон [0, 10]
- x₀ — координата центра по X, диапазон [−10, 10]
- y₀ — координата центра по Y, диапазон [−10, 10]

**Что делает пользователь:**
Вводит значения a, x₀, y₀. По кнопке «Посмотреть значение» на canvas рисуется квадрат с заданными параметрами.

### Игра (страница lv1.html)

**Условие задачи:**
> Дан центр квадрата a = 3. Необходимо найти точку X, если известно, что центр имеет координату (2, 3), а координата y = 4.

**Что ввести:** координату x искомой точки.

**Правильные ответы:** x = 5 или x = −1.

**Как проверяется:**
После ввода ответа рисуется квадрат с параметрами (a=3, x₀=2, y₀=3) и точка (x, 4). Если введённое значение равно 5 или −1 — ответ верный, иначе — неверный. Результат сохраняется в историю.

## Уровень 2 — Круг

### Фигура

Круг — множество точек на плоскости, находящихся на одинаковом расстоянии от центра. Это расстояние называется радиусом.

### Формула попадания

Точка (x, y) находится внутри круга с центром (x₀, y₀) и радиусом r, если:

```
(x − x₀)² + (y − y₀)² ≤ r²
```

### Элементы круга

- радиус: r
- диаметр: d = 2r
- уравнение окружности: (x − x₀)² + (y − y₀)² = r²

### Теория (модалка)

**Что дано:**
- r — радиус круга, диапазон [0, 10]
- x₀ — координата центра по X, диапазон [−10, 10]
- y₀ — координата центра по Y, диапазон [−10, 10]

**Что делает пользователь:**
Вводит значения r, x₀, y₀. По кнопке «Посмотреть значение» на canvas рисуется круг с заданными параметрами.

### Игра (страница lv2.html)

**Условие задачи:**
> Дан круг с центром в точке O. Известно, что центр находится в координате (2, 3), а радиус равен 4. Необходимо найти точку X, если координата y = 4 и точка лежит на правой границе круга.

**Что ввести:** координату x искомой точки.

**Правильный ответ:** x = 5.

**Статус:** проверка реализована как заглушка — сравнение с числом 5 напрямую. В будущем планируется вычисление ответа по формуле.

**Как проверяется:**
После ввода ответа рисуется круг с параметрами (r=4, x₀=2, y₀=3) и точка (x, 4). Если введённое значение равно 5 — ответ верный. Результат сохраняется в историю.

## Уровень 3 — Треугольник

### Фигура

Треугольник — фигура с тремя сторонами и тремя углами. Сумма углов треугольника всегда равна 180°.

### Вершины

Треугольник задаётся тремя вершинами:
- A(x₁, y₁)
- B(x₂, y₂)
- C(x₃, y₃)

В текущем уровне используется треугольник:
- A(−3, 0)
- B(3, 0)
- C(0, 4)

### Формулы

- площадь: S = ½ · |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|
- периметр: P = AB + BC + CA
- длина стороны AB = √((x₂ − x₁)² + (y₂ − y₁)²)

### Проверка попадания

Используются барицентрические координаты или проверка того, что точка лежит по одну сторону от каждой из сторон.

Для каждой стороны вычисляется знак:

```
sign((x₂ − x₁)(y − y₁) − (y₂ − y₁)(x − x₁))
```

Если все три знака совпадают — точка внутри треугольника.

### Теория (модалка)

**Что дано:**
- x — координата точки, диапазон [−10, 10]
- y — координата точки, диапазон [−10, 10]

**Что делает пользователь:**
Вводит значения x и y. По кнопке «Посмотреть значение» на canvas рисуется треугольник A(−3, 0), B(3, 0), C(0, 4) и точка (x, y).

### Игра (страница lv3.html)

**Условие задачи:**
> Дан треугольник с вершинами A(−3, 0), B(3, 0) и C(0, 4). Необходимо найти координату x точки X, если известно, что точка X лежит на стороне AC, а её координата y = 2.

**Что ввести:** координату x искомой точки.

**Правильный ответ:** x = −1.5.

**Статус:** проверка реализована как заглушка — сравнение с числом −1.5 напрямую. В будущем планируется вычисление ответа по формуле.

**Как проверяется:**
После ввода ответа рисуется треугольник с вершинами A(−3, 0), B(3, 0), C(0, 4) и точка (x, 2). Если введённое значение равно −1.5 — ответ верный. Результат сохраняется в историю.

## Как добавить новый уровень

1. Создать `levelN.js` с функциями `initLevelN()` и `levelN()`.
2. Добавить импорт в `app.js`.
3. В `index.html` добавить:
    - кнопку уровня на карте;
    - модальное окно `<div id="th-figure" class="modal">` с теорией;
    - форму, canvas, кнопку «Теория прочитана».
4. Создать `lvN.html` со страницей игры.
5. Создать `Nlv--history.html` со страницей истории.
6. Добавить данные в `data/data.json` (для дальнейшего использования).
7. Добавить формулы и правила в этот файл.
8. Обновить документацию: CHANGELOG.md, docs/LEVELS.md, README.md.

## Ограничения

- Координатная плоскость ограничена диапазоном [−10, 10] по обеим осям.
- Значения полей валидируются на HTML и JS уровнях.
- Ответы уровней 2 и 3 пока захардкожены — вычисление по формуле планируется в следующих версиях.
