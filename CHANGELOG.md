# Changelog

Все значимые изменения проекта MathQuest.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## [0.2.0] - 2026-10-13

### Added

#### Темы оформления

- Файл `css/tokens.css` с дизайн-токенами на CSS-переменных: фон, поверхности,
  линии, текст, основной цвет, цвета источников заданий, статусы, тени, радиусы,
  шрифт
- Светлая и тёмная тема: класс `dark` на `<body>`
- 12 цветовых палитр через атрибут `data-theme`: violet, pink, rose, coral,
  orange, amber, lime, green, teal, sky, blue, graphite — каждая в светлом
  и тёмном варианте
- Сохранение темы и палитры в `localStorage` (ключи `LD` и `COLOR`)
- Синхронизация темы между открытыми страницами через событие `storage`

#### Лабораторная работа №1 (вариант 503302)

- Страница `html/lab1.html`: координатная плоскость, форма и история проверок
- Форма с полями R, X, Y и кнопкой «Проверить точку»
- Функция `validateNumber(raw, min, max)`:
  - проверка на пустое поле
  - проверка на число через `Number.isFinite`
  - проверка диапазона: R от 0 до 100, X и Y от −100 до 100
- Вывод ошибок в подписи полей (`label-r`, `label-x`, `label-y`)
- Поддержка десятичной запятой: `1,5` читается как `1.5`
- Проверка попадания точки в область:
  - I четверть — прямоугольник: `x ≤ R/2`, `y ≤ R`
  - IV четверть — треугольник: `y ≥ x − R/2`
  - III четверть — четверть круга радиусом R/2: `x² + y² ≤ (R/2)²`

#### Координатная плоскость (`canvas.js`)

- Функция `canvas(name)`: рисует оси и сетку, возвращает функцию `lv1(x, y, r, isCorrect)`
- Оси со стрелками и подписями `x`, `y`
- Засечки и подписи R и R/2 на обеих осях
- Закрашенная область варианта, зависящая от R
- Цвет точки по результату: `--ok` при попадании, `--miss` при промахе
- Все цвета берутся из CSS-переменных текущей темы
- Масштабирование колесиком мыши: шаг ×1,1, диапазон от ×0,25 до ×8
- Перетаскивание плоскости мышью
- Ограничение перемещения: не дальше 20 клеток от начала координат
- Сетка всегда совпадает с осями при любом масштабе и сдвиге
- Учёт CSS-растяжения canvas при перетаскивании
- Сохранение в `sessionStorage`: масштаб (`SCALE`), сдвиг (`OFFSET`),
  последняя точка (`LAST_VERSION`)
- Восстановление последней точки после перезагрузки страницы
- Область по умолчанию с R = 15, если точек ещё не было

#### История проверок (`history.js`)

- Функция `history()` возвращает `add`, `clear`, `next`, `prev`
- Хранение в `localStorage` по ключу `HISTORY`
- Новые записи отображаются первыми
- Пагинация по 5 записей на страницу
- Индикатор страниц «текущая / всего»
- Кнопки «назад» и «вперёд» с SVG-иконками, блокируются на краях
- Кнопка «Очистить»
- Колонки таблицы: X, Y, R, итог, время
- Данные записи в атрибутах строки: `data-x`, `data-y`, `data-r`, `data-ans`
- Клик по строке перерисовывает её точку на плоскости (делегирование
  события на `tbody`)

#### Запуск в Docker

- `Dockerfile` на основе `nginx:alpine`
- `nginx.conf`:
  - раздача статики из `/usr/share/nginx/html`
  - главная страница `html/index.html`
  - `Cache-Control: no-cache` для css, js, изображений и шрифтов
- `docker-compose.yml`: контейнер `mathquest-front`,
  порт 8080

### Changed

- Новый интерфейс: боковое меню (Сегодня, Темы, Задачи друзьям,
  Календарь)
- Шрифт заменён на Manrope
- Координаты в canvas считаются от текущего начала координат с учётом
  масштаба и сдвига вместо фиксированного центра
- История хранится под одним ключом `HISTORY` вместо `history:lvN`
- Размер страницы истории уменьшен с 10 до 5 записей

### Fixed

- Числа с запятой давали `NaN`

## [0.1.0] - 2026-09-27

### Added

#### Карта уровней и навигация

- Главная страница с фоновым изображением карты (`index.html`)
- 14 кнопок уровней, расположенных по координатам на карте
- Переходы между страницами: карта → уровень → история → уровень → карта
- Кнопки «История», «Выйти» и «К уровню» на каждой странице
- Модальные окна результата:
  - «Правильно» с кнопками «Дальше» и «Выйти»
  - «Неверно» с кнопкой «Хорошо»

#### Теория

- Модальные окна с теорией для трёх уровней:
  - `th-square` — квадрат: формулы границ и условие попадания
  - `th-circle` — круг: уравнение окружности
  - `th-triangle` — треугольник: площадь, периметр, проверка попадания
    через барицентрические координаты
- Открытие окна по клику на кнопку уровня
- Размер окна ограничен картой, а не экраном
- Состав окна: заголовок, теория, список формул, форма ввода
  (поля зависят от уровня) и ограниченная координатная плоскость
- Кнопка «Теория прочитана» открывает страницу уровня

#### Координатная плоскость

- Модуль `canvas.js` с фабрикой `createCanvas(id)`
- Оси X и Y со стрелками
- Сетка 40 × 40 клеток, шаг вычисляется из размера canvas
- Функции рисования:
  - `drawSquare(a, x, y)` — квадрат с половиной стороны `a` и центром `(x, y)`
  - `drawCircle(r, x, y)` — круг радиусом `r` с центром `(x, y)`
  - `drawTriangle(p1, p2, p3)` — треугольник по трём вершинам
  - `drawPoint(x, y)` — точка
  - `redraw()` — перерисовка плоскости и сетки
- Перевод координат из единиц плоскости в пиксели
- Ось Y направлена вверх, как в математике

#### Формы и валидация

- HTML-валидация полей: `required`, `min`, `max`, `step="0.5"`,
  `pattern="^-?\d+(\.\d+)?$"`
- JS-валидация перед вычислением: пустое поле, `Number.isFinite`, диапазон
- Сообщения об ошибках для каждого поля:
  - «Поле обязательно к заполнению»
  - «Поле должно быть числовым»
  - «Поле должно быть не больше 10»
  - «Поле должно быть не меньше 0» или «не меньше −10»
- Вывод ошибок в `<span class="field-error">` со знаком «!» через `::before`
- Сброс ошибок после успешной проверки

#### Уровни

- Уровень 1, квадрат: поля a, x, y; ответ x = 5 или x = −1
- Уровень 2, круг: поля r, x, y; ответ x = 5 (заглушка)
- Уровень 3, треугольник A(−3, 0), B(3, 0), C(0, 4): поля x, y;
  ответ x = −1,5 (заглушка)
- Запись каждой попытки в историю

#### История попыток

- Модуль `history.js` с фабрикой `createHistory(id)`
- Хранение в `localStorage` по ключу `history:lvN`
- Запись: ответ, признак правильности, дата и время в формате ISO
- Пагинация по 10 записей, кнопки с блокировкой на краях
- Индикатор страниц и счётчик записей
- Кнопка «Очистить историю» с подтверждением через `confirm`
- Колонки: ответ, результат, дата и время
- Зелёный цвет для верных ответов, красный для неверных
- Отдельная страница истории для каждого уровня

#### Стили

- `reset.css` подключается первым, основные стили в `css/style.css`
- Вёрстка на `display: flex`
- Палитра: antiquewhite, `#9a7951`, `#e1ceb9`, `#3b3019`, `#45361c`
- Шрифт JetBrains Mono ExtraBold
- Оформление полосы прокрутки: `scrollbar-color`, `scrollbar-width`
- Псевдоэлементы:
  - `label::before` — звёздочка перед подписью поля
  - `.field-error:not(:empty)::before` — знак «!» перед ошибкой
  - `.title-th::after` — линия под заголовком
- Псевдоклассы `:hover`, `:focus`, `:active`
- Дочерние селекторы: `.form--th > label`, `.background--main > button`
- Селекторы атрибутов: `input[type="text"]`, `input[type="number"]`,
  `input[type="email"]`
- Адаптивные размеры через `clamp()` и `aspect-ratio`

#### Графика

- Фон карты уровней `img/background/img_2.png` с пропорциями
  `aspect-ratio: 1672 / 941`
- Фон страницы уровня `img/background/img_1.png`
- Персонаж-помощник `img/bear.png`

#### Архитектура

- Шесть JS-модулей:
  - `app.js` — точка входа и инициализация
  - `modal.js` — модальные окна с теорией
  - `navigation.js` — переходы между страницами
  - `level1.js`, `level2.js`, `level3.js` — логика уровней
  - `canvas.js` — координатная плоскость
  - `history.js` — история с пагинацией
- Разделение логики уровня на теорию (`initLevelN`) и игру (`levelN`)
- Модули инициализируются только при наличии нужных элементов в DOM
- JSDoc-комментарии к функциям
