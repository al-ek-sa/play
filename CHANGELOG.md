# Changelog

Все значимые изменения.
## [0.1.0] - 2026-09-27

### Added

#### Карта уровней и навигация

- Главная страница с фоновым изображением карты (index.html)
- 14 кнопок уровней, расположенных по координатам на карте
- Кнопки уровней
- Переход между страницами: карта → уровень → история → уровень → карта
- Кнопки «история», «выйти», «К уровню» на каждой странице
- Модальные окна результата: «правильно» и «неверно» с кнопками
  «дальше» и «выйти»(для верных ответов), «хорошо» (для неверных ответов)

#### Теория и модальные окна

- Модальные окна с теорией для трёх уровней:
    - `th-square` — теория квадрата с формулами границ и попадания
    - `th-circle` — теория круга с уравнением окружности
    - `th-triangle` — теория треугольника с формулами площади,
      периметра и проверкой через барицентрические координаты
- Открытие модального окна по клику на кнопку уровня
- Модальное окно ограничена размером карты, не экрана
- Внутри модального окна: заголовок, теория, список формул, форма
  с полями ввода (содержание полей зависит от теории) и canvas (лимитированная координатная плоскость)
- Кнопка «Теория прочитана» — переход на страницу уровня
- Так как координатная плоскость ограничена валидация вводимых данных с 2 видами обработки

#### Canvas и координатная плоскость

- Модуль `canvas.js` — фабрика `createCanvas(id)`
- Отрисовка координатной плоскости: оси X и Y со стрелками
- Отрисовка сетки с шагом, вычисляемым из размера canvas (итоговое полотно 40 × 40)
- API для рисования фигур:
    - `drawSquare(a, x, y)` — квадрат с половиной стороны a
      и центром (x, y)
    - `drawCircle(r, x, y)` — круг с радиусом r и центром (x, y)
    - `drawTriangle(p1, p2, p3)` — треугольник по трём вершинам
    - `drawPoint(x, y)` — точка в координатах (x, y)
    - `redraw()` — перерисовка плоскости и сетки
- Перевод координат из мира в пиксели с учётом масштаба
  (b = width / 40, c = height / 40)
- Инвертирование оси Y для математически корректной системы
  координат

#### Формы и валидация

- HTML-валидация на всех полях:
    - `required` — обязательное поле
    - `min`, `max` — диапазон значений
    - `step="0.5"` — шаг ввода
    - `pattern="^-?\d+(\.\d+)?$"` — регулярное выражение для числовых значений
- JS-валидация перед вычислением:
    - проверка на пустое поле
    - проверка `Number.isFinite`
    - проверка диапазонов для каждого поля
- Отдельные сообщения об ошибках для каждого поля:
    - «Поле обязательно к заполнению»
    - «Поле должно быть числовым»
    - «Поле должно быть не больше 10»
    - «Поле должно быть не меньше 0» / «-10»
- Вывод ошибок в `<span class="field-error">`
- Кастомный псевдоэлемент `::before` со знаком «!» перед текстом
  ошибки
- Сброс ошибок при успешной валидации

#### Уровни игры

- **Уровень 1** (Квадрат): форма с полями a, x, y; canvas с квадратом;
  проверка ответа x = 5 или x = -1
- **Уровень 2** (Круг): форма с полями r, x, y; canvas с кругом;
  проверка ответа x = 5 (заглушка на ответе)
- **Уровень 3** (Треугольник): форма с полями x, y; canvas
  с треугольником A(-3, 0), B(3, 0), C(0, 4); проверка
  ответа x = -1.5 (заглушка на ответе)
- Модальные окна «правильно» / «неверно» для каждого уровня
- Запись попытки в историю при отправке ответа

#### История попыток

- Модуль `history.js` — фабрика `createHistory(id)`
- Сохранение истории в `localStorage` по ключу `history:lvN`
- Запись хранит: ответ, признак правильности, дату и время
  в ISO-формате
- Пагинация: 10 записей на страницу
- Кнопки «предыдущая» / «следующая» с блокировкой на краях
- Индикатор страниц «текущая / всего»
- Счётчик общего числа записей
- Кнопка «Очистить историю» с подтверждением через `confirm`
- Таблица истории с колонками: ответ, результат, дата и время
- Цветовая индикация результата: зелёный для верных, красный
  для неверных
- Отдельные страницы истории для каждого уровня

#### Стили и вёрстка

- Reset.css подключён первым в `<head>`
- Отдельный файл `css/style.css`
- Блочная вёрстка через `display: flex`
- Единая палитра: antiquewhite, #9a7951, #e1ceb9, #3b3019, #45361c
- Единый шрифт JetBrains Mono ExtraBold, serif
- Кастомный скролл: `scrollbar-color`, `scrollbar-width`
- Псевдоэлементы `::before` и `::after`:
    - `label::before` — маркер «*» перед подписью поля
    - `.field-error:not(:empty)::before` — знак «!» перед ошибкой
    - `.title-th::after` — декоративная линия под заголовком
- Псевдоклассы:
    - `:hover` — изменение рамки и фона
    - `:focus` — подсветка активного поля
    - `:active` — нажатие кнопок
- Дочерние селекторы: `.form--th > label`, `.background--main > button`
- Атрибутные селекторы: `input[type="text"]`, `input[type="number"]`,
  `input[type="email"]`
- Адаптивные размеры через `clamp()` и `aspect-ratio`

#### Архитектура и код

- Модульная структура: 6 JS-модулей по задачам
- `app.js` — точка входа, инициализация всех модулей
- `modal.js` — открытие модальных окон с теорией
- `navigation.js` — переходы между страницами
- `level1.js`, `level2.js`, `level3.js` — логика уровней
- `canvas.js` — фабрика canvas с API рисования
- `history.js` — фабрика истории с пагинацией
- JSDoc-комментарии ко всем публичным и приватным функциям
- Async/await в `history.js` для работы с localStorage
- Разделение логики: теория (initLevelN) и игра (levelN)
- Условная инициализация модулей по наличию элементов в DOM
