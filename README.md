# Locus

Интерактивная игра для изучения основ планиметрии на координатной плоскости.

## О проекте

**Locus** — обучающая игра, в которой пользователь знакомится с фигурами на плоскости, вводит данные и проверяет попадание в них. Вместо скучной теории — живой интерактив: меняешь значения, видишь, как меняется рисунок, проходишь уровни от простого к сложному.

Проект создан в качестве учебного.

## Как играть

1. **Теория** — перед уровнем показывается объяснение с интерактивной визуализацией. Можно менять значения и смотреть, как ведёт себя фигура.
2. **Уровень** — даётся радиус, одна из координат и формула. Пользователь вводит вторую координату.
3. **Проверка** — система проверяет, попал ли пользователь в фигуру.
4. **Прогресс** — на каждом уровне несколько задач. История попыток сохраняется.

## Уровни

| Уровень | Фигура | Что дано | Что ввести |
|---------|--------|----------|------------|
| 1 | Квадрат | Радиус, X | Y |
| 2 | Круг | Радиус, Y | X |
| 3 | Треугольник | Формула, одна координата | Вторую |
